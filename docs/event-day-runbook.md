# OC26 Story Vote 当日運用手順

対象：主担当1名、補助スタッフ2名  
所要目安：開始前確認15分、体験30分

## 1. 開始前

1. 運営PCを電源へ接続し、スリープを無効にする。
2. 有線LANを接続する。可能ならスマートフォンのテザリングも予備として準備する。
3. PowerShellでプロジェクトを開き、`npm test`を実行する。
4. 次を実行する。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-event.ps1
```

5. 開発用PIN `260822` とは異なる当日用PINを入力する。
6. 表示された `https://...trycloudflare.com` をコピーする。
7. 4画面を開く。

| 用途 | URL末尾 | 使用端末 |
| --- | --- | --- |
| 参加者 | `/participant` | 参加者PC・スマートフォン |
| 中央表示 | `/display` | 中央モニター |
| 運営 | `/operator` | 主担当PC |
| スタッフ | `/support` | 補助スタッフ端末 |

8. `/health/ready` が `{"status":"ready"}` になることを確認する。
9. 参加者端末2台以上でA・B・Cの投票変更を試す。
10. 「予備接続中」と表示されても、投票が約3秒以内に反映されれば運用可能。

## 2. 役割分担

- 主担当：運営画面、進行、締切、抽選、障害判断。
- 補助1：参加者の画面・QRコード・再読み込み支援。
- 補助2：中央表示の確認、障害時の挙手数集計。

補助スタッフは [スタッフ用クイックガイド](staff-quick-guide.md) だけで対応できる。PIN入力、リセット、サーバー再起動は主担当のみが行う。

## 3. 30分進行

1. 運営画面でログインする。
2. 「開始」→「次へ」→「次へ」で説明を進める。
3. 「投票開始」を押す。
4. 参加者へA・B・Cから選ぶよう案内する。
5. 「投票を締め切る」を押す。
6. 「抽選実行」を押す。
7. 「次のラウンドへ」を押し、第4ラウンドまで繰り返す。

ボタンは一度だけ押す。反応が遅い場合も連打せず、画面更新を待つ。

## 4. 障害時

### 1台だけ動かない

1. 再読み込みする。
2. URLを開き直す。
3. 別端末を案内する。

### 複数台が動かない

1. 10秒待つ。
2. `/support` と `/health/ready` を確認する。
3. Quick Tunnelを再起動した場合は、新しいURLを案内する。
4. 3分以内に戻らなければ、運営画面から「緊急時：挙手投票へ切り替える」を押す。
5. 補助スタッフがA・B・Cの挙手を数える。

### サーバーが停止した

1. `start-event.ps1`をもう一度実行する。
2. 投票途中だったラウンドは準備状態へ戻るため、再投票を案内する。
3. 復旧しなければ挙手投票へ移行する。

## 5. 終了

1. 運営画面の「現在状態を保存」でJSONを保存する。
2. PowerShellで `Ctrl+C` を押してTunnelを終了する。
3. 参加者情報・個別票は保存されない。`data`フォルダには進行状態だけが残る。

## 合格確認

- 4画面が開く。
- 参加者2台以上で投票変更できる。
- 締切後に投票できない。
- 抽選と次ラウンド進行ができる。
- 補助スタッフが再読み込み案内と挙手集計を実行できる。
- 通信障害から3分以内に再投票または挙手投票へ移行できる。
